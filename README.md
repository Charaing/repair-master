# REPAIR MASTER — 전자기기 사설 수리점 시뮬레이터

스마트폰을 직접 한 층씩 분해·조립하며 고치는 수리점 운영 시뮬레이션 게임입니다.
설치·서버 없이 브라우저에서 바로 실행됩니다 (PC·모바일).

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages 주소로 접속하세요.
- 첫 손님(화면 파손)이 튜토리얼입니다. 메뉴 → 튜토리얼 가이드에서 다시 볼 수 있습니다.
- 진행 상황은 브라우저(localStorage)에 자동 저장되며, 컴퓨터 → 시스템에서 내보내기/가져오기할 수 있습니다.

## 현재 버전 (v0.1)
- 가상 브랜드 스마트폰 4종(노바 X12 · 픽시스 S3 · 루멘 A5 · 오르빗 M7) + 무선 게임 컨트롤러(케스트렐 G1), 구조가 서로 다름
- 나사(꾹 눌러 돌리기)·가열·접착 절단·클립·커넥터·아랫면(충전 포트) 보기 등 직접 조작 분해
- 진단 검사 11종(컨트롤러 입력 검사 포함), 부품몰(업체 3곳)·택배·반품, 재고, 장비, 경제·대출(가상 은행), 스킬, 수리 기록·보증, 교과서
- 작업대에서 수리 중인 기기 바꾸기(분해 상태 유지)

## 아직 구현되지 않은 것
- 태블릿·노트북·데스크톱·콘솔 단계 (게임 안에서 "준비 중"으로 표시)
- 컨트롤러 스틱·트리거는 게임 속 가상 설계로 교체형 모듈입니다(실제 제품은 납땜된 경우가 많음).
- 배터리·가열 작업은 실제 절차가 아닌 교육용 가상 미니게임입니다.

등장하는 브랜드와 모델은 모두 가상입니다.
